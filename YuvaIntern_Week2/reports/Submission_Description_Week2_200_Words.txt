In this Week 2 task of the YuvaIntern AI Pioneers Internship, I implemented an advanced supervised machine-learning workflow using Python and Scikit-learn. I reused the synthetic customer behaviour dataset prepared during Week 1 so that the work could continue from data preprocessing to model training and evaluation. The dataset contains customer attributes such as age, annual income, purchase frequency, days since last purchase, gender, city tier, membership type and preferred product category. The project explores both classification and regression problems.

For classification, I trained Logistic Regression, Decision Tree, Random Forest and K-Nearest Neighbors models to predict the binary will_purchase target. For regression, I trained Linear Regression and Random Forest Regressor models to estimate average_order_value. I separated the data into training and testing partitions before fitting preprocessing steps. Numerical missing values were handled with median imputation and StandardScaler, while categorical missing values were filled using the most frequent category and transformed through One-Hot Encoding. These operations were placed inside Scikit-learn pipelines to reduce data leakage. Feature selection was also included within the pipelines.

I evaluated classification models using accuracy, precision, recall, F1-score and ROC-AUC. I also performed five-fold stratified cross-validation on the training data and generated a confusion matrix, ROC curve and metric-comparison chart. Regression models were compared using Mean Absolute Error, Root Mean Squared Error and R-squared. The Python program exports metric tables, a JSON summary, evaluation charts and trained model pipelines in Joblib format. The attached Word report presents the methodology and actual results from executing the code. The dataset is synthetic and intended for educational demonstration, so the reported metrics are not claims about real customer behaviour.
